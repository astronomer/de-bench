# Build notes — where the built world differs from the spec

Never ships. Each row is a deliberate call made during generation that a task
author must know before arming a row or writing a check against the affected
table. The module docstrings carry the detail; this is the index. Resolve a
row by fixing the generator, amending the spec chapter, or accepting the built
value — and then delete the row.
